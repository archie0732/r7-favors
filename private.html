目前目標

第一次連接私人 Repository？看設定教學
  1. 建立 Private Repository。在 GitHub 按 New repository ↗，Visibility 選 Private，並勾選 Add a README file，讓 main branch 先存在。網站只會存取這個 Repository，不會替你建立它。
  2. 建立最小權限 Token。用 Fine-grained personal access token ↗：Resource owner 選你的帳號；Repository access 選 Only select repositories 並勾選這個私人庫；Repository permissions → Contents 依用途設為 Read-only（只瀏覽）或 Read and write（新增、修改、上傳縮圖）。其他權限保持預設。不要使用 SSH public key 或 GitHub 密碼。
  3. 填入 Repository。上方欄位可貼 owner/repo、https://github.com/owner/repo，或 https://github.com/owner/repo/tree/branch 指定其他 branch。不需要編輯 config.js。
  4. 解鎖並建立資料檔。貼上 Token 後按解鎖。若該 Repository 還沒有設定中指定的資料 JSON，網站會顯示「建立預設 JSON」（實際路徑會顯示在該畫面上），按一下即可建立含預設類型與標籤的空白資料。
  5. 下次更快。解鎖成功後網址會補上 ?repo=owner/repo，加入書籤即可自動帶入目標；要換另一個私人庫，直接改上方欄位就好。

常見錯誤：出現「找不到 owner/repo」通常是 Token 的 Only select repositories 沒有包含它，而不是網路問題；出現「沒有必要權限」請把 Contents 調成 Read and write。

Repository 必須先在 GitHub 建立；本頁會存取該 Repository，並可建立其中的資料 JSON，但不會建立 Repository 本身。
