第一次連接私人 Repository？設定教學

  1. 建立 Private Repository

    Visibility 選 Private，並勾選 Add a README file，讓 main branch 先存在。

    New repository ↗

  2. 開啟 Fine-grained tokens 頁面

    GitHub 右上角頭像 → Settings → 左側最底的 Developer Settings → Personal access tokens → Fine-grained tokens，再按右上角的 Generate new token。

    Fine-grained tokens ↗

  3. 填 Token name 與 Expiration

    Token name 隨意（例如 favors），Description 可留空，Resource owner 保持自己的帳號。Expiration 建議設一個到期日；選 No expiration 會出現 GitHub 的安全性警告，到期後只要重做這一段再貼一次新 Token 即可。

  4. Repository access 選 Only select repositories

    不要選 All repositories。點 Select repositories 下拉，挑剛剛建立的私人庫，確認下方顯示 Selected 1 repository 且列出 owner/repo。

  5. Permissions 只加 Contents

    在 Permissions 區塊按 Add permissions，搜尋框輸入 conte，勾選 Contents。加入後把右側 Access 從 Read-only 改成 Read and write（只想瀏覽可維持 Read-only，但就不能新增或修改）。Metadata 會被 GitHub 自動加入且標示 Required，不用理它。

  6. Generate token 並立刻複製

    捲到最底按綠色的 Generate token。產生後畫面只會顯示這一次，用右邊的複製鈕把 github_pat_… 收好；忘了複製就刪掉重做。不要把它貼進 config.js、commit 或任何聊天視窗。

  7. 回到本頁貼上 Repository 與 Token

    上方第一欄填 owner/repo、完整 GitHub 網址或 …/tree/branch；第二欄貼剛剛複製的 Token。想在這個分頁重整後免再貼一次，就勾「在此分頁期間暫存」，關掉分頁即清除。按解鎖私人連結庫。

  8. 建立第一份資料

    資料檔還不存在時，解鎖後會出現「建立預設 JSON」，按一下即可建立，路徑顯示在該畫面上。

  9. 下次更快

    解鎖成功後網址會補上 ?repo=owner/repo，加入書籤即可自動帶入；換一個私人庫只要改上方欄位。Token 過期或外洩時，回 Fine-grained tokens 頁按 Delete 再重新產生。
